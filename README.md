# ABOUT THIS:

Since it’s intended for bulk use, it includes a triple license that allows for starter kit use—for example, if you want to create a template kit without mandatory attribution.

In summary, what does this triple license entail?

Basically, ALL SOURCE CODE IS UNDER THE DUAL LICENSE—that is, the MIT-0 and the BSD-0

However, regarding the assets, it states that they are all licensed under CC0 1.0, and that CC0 1.0 applies only to the assets and not to the source code, to avoid legal ambiguity, etc.
